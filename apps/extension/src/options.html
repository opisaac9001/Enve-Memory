Right-click a page, selection or link to save it instantly. Instant saves go to the project you last picked.

Change shortcuts in your browser's extension shortcut settings.

Import browser bookmarks

Adds every bookmark in this browser to Enve Memory in one go. Folder names become tags. Pages you've already saved get the new tags and aren't duplicated, so running it again is safe. Whether pages are fetched for full-text search follows Enve Memory's own settings.
