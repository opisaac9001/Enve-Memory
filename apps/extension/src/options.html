Enve Memory

Save pages, links and selections from your browser to your own library.

Connection

Where Enve Memory is running. The default works when the app or enve-memory serve runs on this computer.

Create one in a terminal. It's shown once, and stays in this browser profile only.

enve-memory clients add "Browser" --scope read,capture

Saving

Click the toolbar button to save the page with a project, tags and a note. Right-click a page, selection or link to save it instantly. Instant saves go to the project you last picked in the popup.

Change shortcuts in your browser's extension shortcut settings.
